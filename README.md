# 📚 APLIKASI PERPUSTAKAAN MINI

## 1. Deskripsi Projek
Aplikasi Perpustakaan Mini merupakan program sederhana berbasis Java yang digunakan untuk mengelola data buku di perpustakaan. Aplikasi ini dibuat untuk mempermudah proses pengelolaan buku, pencarian, peminjaman, dan pengembalian buku.

## 2. Tujuan
- Mempermudah pengelolaan data buku.
- Mempermudah pencarian buku.
- Mencatat status ketersediaan buku.
- Membantu proses peminjaman dan pengembalian buku.

## 3. Fitur Aplikasi
1. **Tambah Buku** – Menambahkan data buku baru.
2. **Tampilkan Buku** – Menampilkan seluruh daftar buku.
3. **Ubah Buku** – Mengubah judul dan nama penulis.
4. **Hapus Buku** – Menghapus data buku.
5. **Pinjam Buku** – Mengubah status buku menjadi dipinjam.
6. **Kembalikan Buku** – Mengubah status buku menjadi tersedia.
7. **Cari Buku** – Mencari buku berdasarkan judul atau nomor buku.

## 4. Spesifikasi Aplikasi
- Bahasa pemrograman: Java
- Platform coding: Programiz Online Compiler
- Kapasitas maksimal: 100 buku
- Data awal: 10 buku
- Penyimpanan: File buku.txt (pada platform yang mendukung penyimpanan file permanen).

## 8. Cara Menjalankan Program
1. Buka Programiz Online Java Compiler.
2. Salin kode program dari file Main.java.
3. Tempelkan kode ke editor Programiz.
4. Klik tombol Run.
5. Pilih menu sesuai kebutuhan.
6. Ikuti petunjuk yang muncul pada layar.

## 9. Kesimpulan
Aplikasi Perpustakaan Mini dibuat untuk membantu pengelolaan data buku secara sederhana. Dengan adanya fitur tambah, tampilkan, ubah, hapus, cari, pinjam, dan kembalikan buku, pengelolaan perpustakaan menjadi lebih mudah dan terstruktur.
