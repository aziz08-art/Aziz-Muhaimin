# 📚 Perpustakaan Mini - Aziz Muhaimin

Aplikasi Perpustakaan Mini berbasis Java (Console) untuk mengelola data buku: tambah, tampil, ubah, hapus, pinjam, dan kembalikan buku.

**Nama:** Aziz Muhaimin
**Kelas:** X PPLG
**Bahasa:** Java

## 🎯 Deskripsi
Aplikasi ini membantu petugas perpustakaan mencatat buku. Data disimpan dalam array, maksimal 20 buku. Setiap buku punya judul, penulis, status (Tersedia / Dipinjam), dan nama peminjam.
